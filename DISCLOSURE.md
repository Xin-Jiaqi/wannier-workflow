# Disclosure status

**Repository status: private prepublication development.**

This repository may contain implementation details and discussion of internal validation targets. It must remain private until all of the following are complete:

1. manuscript and institutional disclosure review;
2. third-party code, structure, and database rights review;
3. removal or embargo of unpublished benchmark values and candidate identities as required;
4. confirmation that no VASP/POTCAR or credential material exists anywhere in Git history;
5. selection of a software licence and a citable archived release.

Making the repository public is a deliberate release action, not an ordinary settings change. A private GitHub repository is used for version control and collaboration; it is not the paper's public data archive.
